# HLS Grabber Bridge

Міст між сторінкою серіалу й локальною панеллю HLS Grabber.

> Автоматичний обхід написаний під **HDRezka** (rezka.ag і дзеркала): він
> читає розмітку саме цього сайту й звертається до його ендпоінта
> `ajax/get_cdn_series`. На інших сайтах працюватиме хіба що перехоплення
> `.m3u8` із трафіку — і то не всюди.

## Установлення

Найпростіше — з панелі: **Діагностика → Firefox Bridge → «Підключити
Firefox»**. Вона розпакує файли й відкриє потрібне вікно.

Вручну:

1. `about:debugging#/runtime/this-firefox`
2. **Load Temporary Add-on**
3. Вибрати `manifest.json` із цієї теки
4. У попапі розширення поставити той самий порт, на якому працює панель

Firefox вимагає підпису Mozilla для постійного встановлення, тож локальна
збірка живе лише до перезапуску браузера.

**Chromium** теж підійде: `chrome://extensions` → режим розробника → «Load
unpacked». Але перевірялось усе саме у Firefox.

## Доступ до сайтів — обов'язковий

Firefox MV3 **не видає** `host_permissions` при встановленні. Без них content
script не впроваджується взагалі, і сторінка виглядає німою: завантажилась,
адреса правильна, а на повідомлення не відповідає.

Найпідступніше те, що частина сценаріїв усе одно працює: клік по кнопці
розширення дає тимчасовий доступ до активної вкладки, тож ручне сканування з
попапа проходить. А панель, яка відкриває сторінку у фоновій вкладці, мовчки
впирається в таймаут.

Дати дозвіл: у попапі кнопка **«Дозволити доступ»**, або вручну —
Додатки → HLS Grabber Bridge → Дозволи → «Доступ до даних для всіх сайтів».

## Як воно шукає посилання

**Головний шлях — API сайту.** Один запит на епізод повертає всі якості
одразу (360p … 1080p Ultra) з готовими адресами. Плеєр не запускається,
тож і обмежень фонової вкладки немає.

**Запасний — перехоплення трафіку.** Розширення клацає епізоди й ловить
`.m3u8` у мережевих запитах. Повільніше, дає одну якість і потребує
`stay-awake.js`, який переконує сторінку, що вкладка видима: інакше плеєр
у фоні не починає вантажити відео.

Вибір між ними автоматичний — за наявністю `cdnItemId` у розмітці.

**uakino** (`uakino.js`). Плейлист сторінки (блок `.playlists-ajax`) дає
озвучки й серії, а в кожної серії — сторінку плеєра ashdi. Фон розширення
відкриває її з Referer сайту (для цього потрібен дозвіл `webRequestBlocking`)
і дістає з конфігу Playerjs адресу `.m3u8`. Сезон береться з
`.seasons .season-active`: кожен сезон — окрема сторінка.

**Свіжі посилання для черги.** Адреси з API підписані й протухають. Коли
серія з черги отримує відмову на всіх дзеркалах, панель просить розширення
заново взяти адресу цієї серії. Розширення відкриває сторінку у фоні (або
бере вже відкриту), робить один запит `get_stream` і закриває вкладку.

## Порт

І розширення, і панель за замовчуванням працюють на **8787**. Якщо панель не
відповідає на збереженому порту, фон обходить звичні (`PANEL_PORTS` у
`service-worker.js`) і запам'ятовує той, де heartbeat повернув `{"ok": true}`.
Нестандартний порт — у попап руками.

## Після зміни файлів

Підняти версію **одночасно** в `manifest.json` і `assets.go`, інакше панель
не помітить, що у Firefox лишилась стара збірка, і оновлення мовчки не
подіє.

Використовуй лише з тими потоками, до яких маєш доступ.
