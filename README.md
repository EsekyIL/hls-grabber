# hls-grabber

Качає серіали й фільми з HLS через yt-dlp і ffmpeg. Усе крутиться локально.

Працює з **HDRezka** (rezka.ag і дзеркала). Автоматичний обхід зав'язаний на
розмітку цього сайту й на його ендпоінт `ajax/get_cdn_series` — деінде він не
запрацює. Ручний режим із прямими посиланнями бере будь-що.

## Складові

Веб-панель (`cmd/web`) — інтерфейс у браузері: обхід сайту, черга,
діагностика. Розширення для Firefox (`browser-extension`) — міст до сайту,
вшитий у панель і встановлюваний звідти ж.

Будова описана в [ARCHITECTURE.md](ARCHITECTURE.md).

## Потрібно

Windows 10/11, Go 1.22+ для збірки, Firefox для автоматичного обходу.

PowerShell 7 не обов'язковий, але з ним вибір теки відкриває нормальний
провідницький діалог. Без нього — старе вузьке дерево тек із PowerShell 5.1.

yt-dlp і ffmpeg ставити не треба, панель качає їх сама на сторінці
«Діагностика» й звіряє контрольні суми.

## Запуск

```powershell
go build -o build/bin/hls-grabber-web.exe ./cmd/web
.\hls-grabber-web.cmd
```

Далі:

1. **Діагностика → Firefox Bridge → «Підключити Firefox»**. Панель розпакує
   розширення й відкриє `about:debugging`. Там «Load Temporary Add-on» і
   вибрати вже виділений `manifest.json`.
2. **Медіатека** — встав адресу серіалу, «Розібрати».
3. Познач озвучки, «Знайти посилання».
4. Вибери якість, познач серії, «Почати завантаження».

Firefox тримає непідписані розширення лише до перезапуску, тож перший крок
доведеться повторювати після кожного запуску браузера. Після оновлення панелі
— теж: у Діагностиці це видно як «завантажена стара версія».

## Порти

Панель і розширення за замовчуванням працюють на 8787. Якщо порт зайнятий,
підніми панель на іншому й постав те саме число в попапі розширення:

```powershell
.\hls-grabber-web.cmd --port 8790
```

## Пошук посилань

HDRezka віддає адреси через `ajax/get_cdn_series` — той самий ендпоінт, яким
користується її плеєр. Один запит на епізод, у відповіді всі якості від 360p
до 1080p Ultra. Плеєр не запускається.

Якщо ендпоінт недоступний, вмикається запасний шлях: розширення клацає
епізоди й ловить `.m3u8` у трафіку. Повільніше й дає одну якість.

Обхід іде у фоновій вкладці, сидіти на сторінці не треба.

## Файли

```
Videos/
├── Films/
│   ├── Назва фільму.mp4
│   └── Назва фільму (2).mp4
└── Serials/
    └── Назва серіалу/
        └── Season 01/
            └── Озвучка/
                ├── S01E01.mp4
                └── S01E02.mp4
```

Кожна озвучка лежить окремою текою, тож дві озвучки однієї серії не
затирають одна одну. Серію, яка вже є на диску, черга пропускає. Фільм із
назвою, що вже зайнята, зберігається з номером у дужках, а наявний файл
лишається як був.

Теки міняються в «Налаштуваннях».

## Збої

Сайт дає на кожну якість кілька адрес на різних CDN. Коли перша
відповідає помилкою, черга одразу пробує наступну. Якщо не вдалася жодна,
вона чекає й повторює все коло. Скільки разів і з якою паузою, задають
«Повторні спроби» й «Затримка» в «Налаштуваннях». Помилки, які повтор не
виправить (немає теки, не знайдено yt-dlp), не повторюються.

## Обмеження

Один сайт — зміниться його розмітка чи API, доведеться правити адаптер.
Тільки Windows: вибір теки й керування процесами написані під неї. Для
особистого користування; жодного відео проєкт не містить і не поширює.
